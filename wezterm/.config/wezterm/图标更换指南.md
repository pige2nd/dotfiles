# WezTerm 图标更换指南

## 图标文件位置

```
~/.local/share/icons/hicolor/scalable/apps/org.wezfurlong.wezterm.svg
```

把你自己喜欢的图标（PNG 或 SVG 都行）替换到上述路径，保持文件名 `org.wezfurlong.wezterm.svg` 不变。

## 替换后刷新

```bash
gtk-update-icon-cache ~/.local/share/icons/hicolor/
```

然后按 **Alt+F2 → 输入 `r` → 回车** 重启 GNOME Shell 即可生效。

## 多尺寸 PNG（可选）

如果用的是 PNG 图标，建议也放到对应尺寸目录下，以保证各个场景显示清晰：

```bash
# 以 256x256 为例
cp 你的图标.png ~/.local/share/icons/hicolor/256x256/apps/org.wezfurlong.wezterm.png

# 其他尺寸同理
# 可用 python3 + Pillow 批量生成:
python3 -c "
from PIL import Image
import os
img = Image.open('你的图标.png')
home = os.path.expanduser('~')
for size in [16, 22, 24, 32, 48, 64, 96, 128, 256]:
    d = f'{home}/.local/share/icons/hicolor/{size}x{size}/apps'
    os.makedirs(d, exist_ok=True)
    img.resize((size, size), Image.LANCZOS).save(f'{d}/org.wezfurlong.wezterm.png')
"

gtk-update-icon-cache ~/.local/share/icons/hicolor/
```

## 原理说明

Desktop 文件 (`~/.local/share/applications/org.wezfurlong.wezterm.desktop`) 中的 `Icon` 使用的是**绝对路径**：

```
Icon=/home/xx/.local/share/icons/hicolor/scalable/apps/org.wezfurlong.wezterm.svg
```

所以直接替换这个文件即可，不经过图标主题查找，不会被其他主题覆盖。
