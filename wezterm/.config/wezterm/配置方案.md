# WezTerm 配置说明

这是一套面向 Linux / GNOME / Wayland 的 WezTerm 配置，重点是：

- 使用 Catppuccin Mocha 深色主题和 Nerd Font 图标
- 保留清晰、稳定的 Ctrl 快捷键
- 提供 Vim / Neovim 感知的 pane 导航
- 使用 `Alt+B` 作为 Leader
- 提供始终显示的彩色标签栏和状态导航栏
- 可以一键进入“裸模式”，避免和远程 tmux / SSH 的键位冲突

## 文件结构

```text
~/.config/wezterm/
├── wezterm.lua              # 主配置入口
├── colors.lua               # 配色主题
├── tab.lua                  # 彩色标签栏、左侧导航和右侧状态栏
├── mappings.lua             # 快捷键、鼠标绑定、键位模式切换
├── smart-split.lua          # Vim / Neovim 感知的 pane 导航
├── command_palette.lua      # 命令面板扩展
├── plugins.lua              # 可选插件，目前默认关闭
├── wezterm_toggle           # 键位模式状态文件
└── 配置方案.md              # 本说明
```

## 外观

- 主题：Catppuccin Mocha
- 主字体：JetBrainsMono Nerd Font
- 中文字体：Noto Sans Mono CJK SC
- Emoji：Noto Color Emoji
- 字号：12.5
- 行高：1.08
- 连字：关闭
- 窗口内边距：左右 10、上下 8
- 滚动历史：10000 行
- 标签栏：`tabline.wez` 官方默认的 lualine/Powerline 分段式标签栏
- Section 使用半圆粗边；component 使用半圆细线；tab 使用反向半圆粗边
- 已隐藏默认 workspace 名称、电量和时间模块
- 关闭标签或 pane：始终弹出确认

## 导航栏

导航栏由三部分组成：

1. 左侧固定区域：显示 WezTerm 标识和 Leader 提示 `Alt+B`。
2. 中间标签区域：使用 tabline.wez 默认分段式标签风格，活动标签显示索引、父目录、当前目录和 zoom 状态；非活动标签显示索引和进程名。
3. 右侧状态区域：显示 workspace、domain 和当前时间。

标签名称优先级如下：

1. 通过命令面板手动设置的名称
2. 当前工作目录的最后一级目录名
3. pane 的进程标题

因此，重命名标签后不会再被目录名覆盖。

## 全局快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+C` | 复制 |
| `Ctrl+Shift+V` / `Ctrl+V` | 粘贴 |
| `Ctrl+Shift+T` | 新建标签 |
| `Ctrl+Shift+W` | 关闭当前 pane |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 |
| `Alt+1` ~ `Alt+9` | 跳转到指定标签 |
| `Ctrl+Shift+F` | 搜索 |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+Shift+L` | 启动器 |
| `Ctrl+=` / `Ctrl+-` | 放大 / 缩小字体 |
| `Ctrl+0` | 重置字体大小 |
| `Ctrl+Shift+R` | 重载配置 |
| `Ctrl+Alt+0` | 切换完整键位 / 裸模式 |

## Leader 快捷键

Leader 是 `Alt+B`，按下后释放，再按以下按键。完整模式下该按键由 WezTerm 截获，不会传给 zsh：

| 按键 | 功能 |
|---|---|
| `c` | 新建标签 |
| `x` | 关闭当前 pane |
| `X` | 关闭当前标签 |
| `n` / `p` | 下一个 / 上一个标签 |
| `1` ~ `9` | 跳转到指定标签 |
| `[` | 进入 Copy Mode |
| `]` | 搜索 |
| `l` | 打开启动器 |
| `\|` | 分屏 |
| `-` | 分屏 |
| `z` | 放大 / 恢复当前 pane |
| `H` / `J` / `K` / `L` | 调整 pane 大小 |

## Pane 导航

这些快捷键不需要 Leader：

| 快捷键 | 普通 shell | Neovim 中 |
|---|---|---|
| `Ctrl+h/j/k/l` | 切换 pane | 透传给 Neovim |
| `Alt+h/j/k/l` | 调整 pane 大小 | 透传给 Neovim |

Neovim 需要设置以下环境变量，配置才会识别当前 pane：

```bash
export IS_NVIM=true
```

通常可以在 Neovim 的启动配置中设置，或者通过 tmux / shell wrapper 传递。

## Copy Mode

进入方式：`Leader` + `[`

- `h/j/k/l` 或方向键：移动
- `Space`：开始选择
- `Shift` + 方向键：扩展选择
- `Enter`：复制并退出
- `q` / `Esc`：退出而不复制

## 鼠标行为

- `Ctrl` + 左键：打开链接
- 右键：有选中文本时复制，否则粘贴
- 普通终端滚轮：每次滚动 1 行
- alt-screen 程序：滚轮交给程序自己处理
- `Shift` + 左键：绕过 TUI 鼠标捕获进行选择

鼠标关闭标签时会弹出确认。关闭单个 pane 请使用 `Leader+x` 或 `Ctrl+Shift+W`。

## 键位模式切换

`Ctrl+Alt+0` 会在两个模式间切换：

- 完整模式：启用本配置中的所有快捷键
- 裸模式：清空自定义键盘快捷键，适合 SSH 到远程 tmux，避免本地快捷键被 WezTerm 截获

状态保存在 `wezterm_toggle` 中。当前默认值是 `false`，表示启动时使用完整模式。鼠标绑定和 Copy Mode 仍然保留。

## Wayland / XWayland

当前使用原生 Wayland，使输入法候选窗与 niri 的输出缩放保持一致。`wezterm.lua` 中的 `enable_wayland` 应保持为 `true`。niri 下是否显示独立标题栏和窗口按钮取决于 Wayland 装饰支持；不要仅为标题栏按钮切回 XWayland，否则 HiDPI 下的 Fcitx 候选窗可能漏掉输出缩放。

## 命令面板

`Ctrl+Shift+P` 打开命令面板，其中包含：

- Rename tab：重命名当前标签

## 插件

当前使用 `michaelbrusegard/tabline.wez` 提供标签栏。`resurrect` 和 workspace switcher 保留在 `plugins.lua` 中，但默认没有加载。

## 常用检查命令

```bash
wezterm show-keys
wezterm ls-fonts
```

配置修改后会自动重载，也可以使用 `Ctrl+Shift+R` 手动重载。
