# WezTerm 配置说明

这是一套面向 Linux / GNOME / Wayland 的 WezTerm 配置，重点是：

- 使用 Catppuccin Mocha 深色主题和 Nerd Font 图标
- 保留清晰、稳定的 Ctrl 快捷键
- 提供 Vim / Neovim 感知的 pane 导航
- 使用 `Alt+B` 作为 Leader
- 提供始终显示的静态方框标签栏
- 可以一键进入“裸模式”，避免和远程 tmux / SSH 的键位冲突

## 文件结构

```text
~/.config/wezterm/
├── wezterm.lua              # 主配置入口
├── colors.lua               # 配色主题
├── tab.lua                  # wezterm-tabs 标签栏设置
├── mappings.lua             # 快捷键、鼠标绑定、键位模式切换
├── smart-split.lua          # Vim / Neovim 感知的 pane 导航
├── command_palette.lua      # 命令面板扩展
├── plugins.lua              # 可选插件，目前默认关闭
├── wezterm_toggle           # 键位模式状态文件
└── 配置方案.md              # 本说明
```

## 外观

- 主题：Catppuccin Mocha
- 主字体：SF Mono
- 中文字体：Noto Sans Mono CJK SC
- Emoji：Noto Color Emoji
- 字号：12.5
- 行高：1.08
- 连字：关闭
- 窗口内边距：左右 10、上下 8
- 滚动历史：10000 行
- 标签栏：基于 `yriveiro/wezterm-tabs` 的方框 / 括号风格
- 右侧固定显示 `[local]`；左侧不再显示独立状态块
- 当前标签使用 Catppuccin 蓝色底，和紫色状态块明确区分
- 标签之间无空隙并保持等宽；标签增多时会像 Chrome 一样同步缩窄，同时为
  `[local]` 保留显示空间
- 每个标签显示从 1 开始的序号和标题；可识别时附带进程图标
- 仅响应标签格式化和配置重载事件，不注册周期性状态更新或定时器
- 关闭标签或 pane：始终弹出确认

## 标签栏

标签栏由 `wezterm-tabs` 进行事件驱动的静态格式化，最终显示为
`[1 标题] [2 标题] [local]`。标签标题仍可通过命令面板手动重命名；
插件不注册 `update-status`、定时器、子进程或文件读取。可选的 pane/zoom 查询
也保持关闭，只在 WezTerm 需要重新计算标签显示时执行格式化。本地兼容层会
保留多词标题的首词，避免上游把它误判为进程名后将其丢弃；超出 24 列的标题
仍会按标签宽度截断。

从旧 `tabline.wez` 切换后需要完整退出所有 WezTerm 进程再启动一次；配置热
重载无法注销旧进程已经注册的状态回调。右侧 `[local]` 是固定文字，只在
配置重载时设置，不会轮询键位模式、域名或主机名。

## 全局快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+C` | 复制 |
| `Ctrl+Shift+V` / `Ctrl+V` | 粘贴 |
| `Ctrl+Shift+T` | 新建标签 |
| `Ctrl+Shift+W` | 关闭当前 pane |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 |
| `Alt+1` ~ `Alt+9` | 跳转到指定标签 |
| `Ctrl+Shift+F` | 搜索 |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+Shift+L` | 启动器 |
| `Ctrl+=` / `Ctrl+-` | 放大 / 缩小字体 |
| `Ctrl+0` | 重置字体大小 |
| `Ctrl+Shift+R` | 重载配置 |
| `Ctrl+Alt+0` | 切换完整键位 / 裸模式 |

## Leader 快捷键

Leader 是 `Alt+B`，按下后释放，再按以下按键。完整模式下该按键由 WezTerm 截获，不会传给 zsh：

| 按键 | 功能 |
|---|---|
| `c` | 新建标签 |
| `x` | 关闭当前 pane |
| `X` | 关闭当前标签 |
| `n` / `p` | 下一个 / 上一个标签 |
| `1` ~ `9` | 跳转到指定标签 |
| `[` | 进入 Copy Mode |
| `]` | 搜索 |
| `l` | 打开启动器 |
| `\|` | 分屏 |
| `-` | 分屏 |
| `z` | 放大 / 恢复当前 pane |
| `H` / `J` / `K` / `L` | 调整 pane 大小 |

## Pane 导航

这些快捷键不需要 Leader：

| 快捷键 | 普通 shell | Neovim 中 |
|---|---|---|
| `Ctrl+h/j/k/l` | 切换 pane | 透传给 Neovim |
| `Alt+h/j/k/l` | 调整 pane 大小 | 透传给 Neovim |

Neovim 需要设置以下环境变量，配置才会识别当前 pane：

```bash
export IS_NVIM=true
```

通常可以在 Neovim 的启动配置中设置，或者通过 tmux / shell wrapper 传递。

## Copy Mode

进入方式：`Leader` + `[`

- `h/j/k/l` 或方向键：移动
- `Space`：开始选择
- `Shift` + 方向键：扩展选择
- `Enter`：复制并退出
- `q` / `Esc`：退出而不复制

## 鼠标行为

- `Ctrl` + 左键：打开链接
- 右键：有选中文本时复制，否则粘贴
- 普通终端滚轮：每次滚动 1 行
- alt-screen 程序：滚轮交给程序自己处理
- `Shift` + 左键：绕过 TUI 鼠标捕获进行选择

鼠标关闭标签时会弹出确认。关闭单个 pane 请使用 `Leader+x` 或 `Ctrl+Shift+W`。

## 键位模式切换

`Ctrl+Alt+0` 会在两个模式间切换：

- 完整模式：启用本配置中的所有快捷键
- 裸模式：清空自定义键盘快捷键，适合 SSH 到远程 tmux，避免本地快捷键被 WezTerm 截获

状态保存在 `wezterm_toggle` 中。当前默认值是 `false`，表示启动时使用完整模式。鼠标绑定和 Copy Mode 仍然保留。

## Wayland / XWayland

当前在 niri 下使用 XWayland，`wezterm.lua` 中的 `enable_wayland` 保持为
`false`。这是经整屏截图验证的稳定路径：原生 Wayland 下 WezTerm 与
niri/DMS 的窗口装饰高度协商会使最后一行落入几何裁剪区；XWayland 下终端
内容、圆角和焦点边框正常。

2× 缩放由 `~/.Xresources` 中已验证的 `Xft.dpi: 192` 处理。这是 XWayland
协议边界修正，不要再叠加 Fcitx `ForceWaylandDPI` 或其他全局 DPI 放大。如要
重试原生 Wayland，必须作为单变量实验，并同时验证最后一行与输入法候选框。

## 命令面板

`Ctrl+Shift+P` 打开命令面板，其中包含：

- Rename tab：重命名当前标签

## 插件

标签栏使用 `yriveiro/wezterm-tabs`。`resurrect` 和 workspace switcher
保留在 `plugins.lua` 中，但默认没有加载。

## 常用检查命令

```bash
wezterm show-keys
wezterm ls-fonts
```

配置修改后会自动重载，也可以使用 `Ctrl+Shift+R` 手动重载。
