# pref-by-location.yazi

来源：[boydaihungst/pref-by-location.yazi](https://github.com/boydaihungst/pref-by-location.yazi)。本目录保留 WSL 已使用的插件快照，许可证见 LICENSE。

当前在 Yazi 26.8.15 使用。上游已停止维护，声明支持 26.5.6 至 26.9.1；升级 Yazi 时需核对兼容性。

初始化和快捷键分别位于 `init.lua` 与 `keymap.toml`。目录偏好保存到 `$XDG_STATE_HOME/yazi/pref-by-location`，未设置时使用 `~/.local/state/yazi/pref-by-location`，不随配置提交。
